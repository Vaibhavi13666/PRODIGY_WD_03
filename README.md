# 🎮 Tic Tac Toe Web Application

A modern and responsive Tic Tac Toe web application developed as **Task 03** during my Web Development Internship at **Prodigy Infotech**.

The game is built using **HTML, CSS, and JavaScript** with a clean and interactive user interface.

## ✨ Features

- 🎮 Two-player Tic Tac Toe
- ❌ Player X and ⭕ Player O
- 🏆 Automatic winner detection
- 🤝 Draw detection
- 📊 Score tracking
- 🔄 New Game functionality
- 🗑️ Reset Score functionality
- 💾 Score persistence using Local Storage
- 📱 Responsive design
- 🎨 Modern dark-themed interface
- ✨ Interactive hover and winning animations

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
